# Nexa logo

| File | Use |
|---|---|
| `nexa-mark.svg`, `nexa-mark-<size>.png` | The mark alone: icons, favicons, avatars (16 to 1024 px) |
| `nexa.ico` | Windows icon (16, 32, 48, 64, 128, 256) |
| `nexa-logo-on-dark.svg` / `.png` | Mark and name, on a dark background |
| `nexa-logo-on-light.svg` / `.png` | Mark and name, on a light background |

The mark is the same on any background; only the name's colour changes.

| Colour | Hex |
|---|---|
| Tag | `#E98A6E` |
| N | `#0D0F14` |
| Name on dark | `#E8EAED` |
| Name on light | `#1F2328` |

The PNGs have transparent backgrounds.
