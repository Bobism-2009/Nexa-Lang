NexaC Command Line
==================

USAGE
  NexaC init [dir]           Scaffold new project (current dir or dir/)
  NexaC build [dir]          Build .nxa with fn main() or fn __init__()
  NexaC upgrade              Check GitHub for a newer NexaC and offer to install it
  NexaC <file.nxa> [-o <executable>]
  NexaC <file.nxa> --run
  NexaC <file.nxa> --source <output.cpp>
  NexaC --help [page|module]
  NexaC --version

  NexaC upgrade [--check] [--yes] [--user | --all-users]
    Looks up the latest GitHub release. If it is newer than this NexaC, asks
    whether to install that version number. Yes: download, extract, replace
    this NexaC, delete the temp files.
    Also asks whether to update for all users (Windows UAC / sudo).
    --check       Print versions only; do not install
    --yes, -y     Install without the first yes/no prompt
    --user        This NexaC only (no all-users prompt)
    --all-users   System install (Program Files /usr/local/bin); may UAC/sudo

OPTIONS
  -o <name>       Output executable or library name
  --source <f>    Emit C++ only, do not compile
  --preserve-names, -p  Keep function names (readability)
  --small         Optimize for smaller output (-Os)
  --dll     Build Windows .dll (default: -Os; link with strip for size)
  --shared  Build .dylib (macOS) or .so (Linux)
  --win     Build Windows .exe (mingw-w64 from Linux)
  --wasm    Build WebAssembly (em++ → .js+.wasm, or WASI-SDK → .wasm).
            If the WASM toolchain is missing, a popup asks to install Emscripten.
  --no-console    Build Windows GUI .exe with no console window
  fn __init__() in a DLL/SO/dylib is auto-executed when the library is loaded
  --run, -r       Compile to temp file and run
  --help, -h      Show help
  --version, -v   Show version
