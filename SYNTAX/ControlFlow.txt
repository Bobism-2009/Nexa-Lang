Nexa Control Flow
=================

CONDITIONALS
  if (cond) { ... }
  if (cond) { ... } else { ... }
  if (cond) { ... } else if (cond) { ... } else { ... }

  Braces are optional for a single statement (C-style):
    if (x > 5) io.println("big");
    if (x % 2 == 0) io.println("even"); else io.println("odd");
    if (a) doA(); else if (b) doB(); else doC();
  This also applies to while and for:
    while (i < 3) i = i + 1;
    for (j, 3) io.println(j);
  Use braces { } when the body has more than one statement.

COMPARISONS
  ==  !=  <  <=  >  >=

LOGICAL OPERATORS
  &&   and
  ||   or
  !    not
  Precedence: ! before && before ||

  Examples:
    if (x > 0 && x < 10) { ... }
    if (!(x > 0)) { ... }
    if (a || b) { ... }

SWITCH
  switch (expr) {
    case 0:
      stmts
      break;
    case 1:
    case 2:
      stmts
      break;
    default:
      stmts
  }
  - Int switch: expr is int, case values are integer literals
  - String switch: expr is string, case values are string literals
  - Cannot mix int and string cases in same switch
  - Use break; to exit (C-style fall-through if omitted)
  - default is optional

LOOPS
  for (i, n) { ... }  - loop i from 0 to n-1
  while (cond) { ... }
  while (true) { ... }   - infinite loop
  while (false) { ... }  - never runs
  break;                 - exit loop immediately
  continue;               - skip to next iteration
  true, false - boolean literals (like C++)

  Example:
    while (i < 10) {
      io.println(i);
      i = i + 1;
    }

GOTO / LABELS
  label:        - define a label (an identifier followed by ':')
  goto label;   - jump to a label in the same function

  - Labels and goto are function-local (you cannot jump between functions).
  - Forward and backward jumps are both allowed.
  - Like C, you cannot jump forward over a variable declaration and then use
    that variable; the compiler will reject it.

  Example:
    let i = 0;
  start:
    if (i >= 5) { goto done; }
    io.println(i);
    i = i + 1;
    goto start;
  done:
    io.println("done");
