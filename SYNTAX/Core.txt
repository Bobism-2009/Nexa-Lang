Nexa Core Syntax
================

INLINE C++ (escape hatch; requires #include <std/inline>)
  inline_cpp! {
    // C++ statements; compiled by Clang, not parsed by Nexa
  }

ENTRY POINT
  fn main() {
    ...
  }
  fn main(args: []string): void {
    ...
  }
  - Every executable must have exactly one fn main()
  - Optional command line: one parameter named as you like, type must be exactly []string.
    Index 0 is the program name/path as in C argv[0]; 1.. are arguments. Use len(args) for the count.
  - DLL builds (--dll) do not require main

STRUCTS
  struct Name {
    field: int;
    other: string;
    nested: InnerStruct;   // InnerStruct must be declared earlier in the file
  }
  - Field types: int, unsigned int, string, bool, float, char, unsigned char, *T pointers, or another struct name
  - Optional semicolon after the closing }

  Variables:
    let p: Point;           - value-initialized (fields zeroed / empty string)
    let q: Point = p;       - copy from another value of the same struct type
  Field access (expression):  p.x   p.label
  Field assignment:           p.x = 10;   p.label += "suffix";
  Function parameters:       fn use(pt: Point) { ... }

  - Reading a struct field in a let initializer requires an explicit type:
    let n: int = p.x;
  - Fixed-size arrays of structs are not supported

ENUMS
  enum Name {
    VariantA;
    VariantB;
  }
  - Transpiles to C++ enum class Name : int { ... } (scoped; underlying int)
  - Type in let / parameters:  let x: enum Name = Name.VariantA;
  - Variants in expressions:    Name.VariantB
  - Uninitialized:              let x: enum Name;   // first variant in the enum body
  - switch: only enum cases together (case Name.A:) or only int or only string — do not mix

FUNCTIONS
  fn name() { ... }           - No parameters, void return
  fn name(a, b) { ... }      - Parameters (default int)
  fn name(a: int, b: string, flag: bool, x: float, c: char, p: Point) { ... }  - Typed parameters (struct or enum: fn f(c: enum Color) { ... })
  fn name(a: int, b: int = 0, msg: string = "hi") { ... }  - Default argument values
  return expr;               - Return a value (int) from a value-returning function
  return;                   - Early exit from a void function (no value)
  name();                    - Call (statement)
  let z = name(x, y);        - Call (expression)
  name(1);                   - Omit trailing defaults (same as name(1, 0, "hi") above)

  - Parameters: default int, or add : int / : string / : bool / : float / : char / : YourStruct / : enum YourEnum
  - Defaults: write = expr after the type (or after the name if untyped). Once one parameter
    has a default, every following parameter must also have a default.
  - Defaults are filled in at the call site (omitted args use the default expressions).
  - Return type inferred: int if any `return expr;` appears (including inside if/while/for), else void
  - Do not mix `return;` and `return expr;` in the same function; main() only uses value returns (`return expr;` or implicit exit)
  - In main(), `return;` is compiled as `return 0;`
  - Use --preserve-names to keep names in output (default: mangle)

VARIABLES
  let name = value;
  let name;              - uninitialized (defaults to string "")
  let name: string;      - typed, uninitialized
  let name: int = 42;    - typed with initializer
  let const name: string = "Bob";  - constant (immutable, must have initializer)

  Global variables (top-level, outside functions):
    let count = 0;
    let msg = "hello";
    let y = x + 1;   // can use other globals
    No io.readln() or dll.load() at global scope.

  Local variables (inside functions): same syntax.

  Types (inferred or explicit):
    int:    let x = 42;  let n: int = -10;  let c: int;
    unsigned int: let u: unsigned int = 42;  let w: unsigned int;
    string: let s = "hello";  let name: string = io.readln();  let msg: string;
    bool:   let ok = true;  let flag: bool = false;  let b: bool;
    float:  let pi = 3.14;  let x: float = 2.5;  let f: float;
    char:   let c = 'A';  let ch: char = 'x';  let letter: char;
    unsigned char: let b: unsigned char = 255;
    pointers: let p: *int = &x;  let q: **int;  (see POINTERS)

POINTERS (no GC — manual, C-style)
  Type:     *T   **T   (prefix star on the type)
  Address:  &x
  Deref:    *p
  Assign:   *p = value;   *p += 1;
  Null:     null   (emits C++ nullptr)
  Examples:
    let x = 10;
    let p: *int = &x;
    *p = 20;              // x is now 20
    io.println(*p);
    let q: *int = null;
    if (q != null) { ... }
    fn bump(p: *int) { *p = *p + 1; }
  Struct fields may be pointers:  field: *int;
  There is no garbage collector; dangling pointers are undefined behavior (same as C/C++).

  String escapes: \n \t \r \\ \" \xHH (hex ASCII, e.g. \x41 = 'A')
  Raw strings: R"()" or R"delim(...)delim" - no escapes, can contain newlines and "

  Initializers:
    - Number:     let x = 42;
    - Float:      let pi = 3.14;  let x = .5;
    - Char:       let c = 'A';  let nl = '\n';
    - String:     let s = "hi";  s[i] returns char;  s[i] = 'x';
    - Array:      let arr = [1, 2, 3];  arr[i] = x;  (int elements)
    - String array: let names = ["bob", "jessica"];  names[i] returns string
    - io.readln:  let s = io.readln();
    - io.getline: let s = io.getline(file.read("data.txt"), 2);
    - file.read:  let s = file.read("path");  (requires std/file)
    - dll.load:   let h = dll.load("./lib.so");  (requires std/dll)
    - Expression: let sum = a + b;  let x = add(2, 3);
    - Bool:       let ok = true;  let flag = false;

  Reassignment:
    x = expr;   (variable must be declared first; const variables cannot be reassigned)
    x++;  x--;  (increment/decrement by 1)
    x += n;  x -= n;  x *= n;  x /= n;  x %= n;  (compound assignment)
    x &= n;  x |= n;  x ^= n;  x <<= n;  x >>= n;  (bitwise compound assignment)
    s += "x";  (string concatenation - += works for strings)

ARITHMETIC
  + - * / %
  Precedence (tightest first): * / % ; + - ; << >> ; & ; ^ ; |
  Bitwise: & | ^  (binary),  ~  (unary NOT),  << >>  (shift)
  int and float (int + float promotes to float)

CASTS (C-style)
  (int)expr    (float)expr    (char)expr    (bool)expr    (string)expr
  (unsigned char)expr    (unsigned int)expr
  Same precedence as unary operators. Examples:
    let x: float = 3.7;
    let n = (int)x;           // 3
    let s = (string)n;        // "3"
    let c = (char)65;         // 'A'
    let f = (float)(int)s;    // parse then cast (s must be string)

STRING METHODS (core; no #include required)
  Method syntax on any string value (variable, literal, or parenthesized expression):

    s.upper()              -> string   ASCII upper-case
    s.lower()              -> string   ASCII lower-case
    s.trim()               -> string   strip leading/trailing whitespace
    s.len()                -> int       length (same as len(s))
    s.contains(sub)        -> bool      true if sub occurs in s
    s.starts_with(prefix)  -> bool
    s.ends_with(suffix)    -> bool
    s.index_of(sub)        -> int       first index of sub, or -1 if absent
    s.replace(from, to)    -> string   replace every occurrence
    s.substring(start, n)  -> string   n characters from start (n < 0 = to end)
    s.repeat(n)            -> string   s concatenated n times
    s.split(sep)           -> []string split on sep (empty sep -> [s])

  Examples:
    let parts = "a,b,c".split(",");      // []string of length 3
    for (i, len(parts)) { io.println(parts[i]); }
    for (p in parts) { io.println(p); }  // same, range-for
    io.println("Hello".upper());          // HELLO
    io.println(name.trim().lower());      // chaining is allowed
    if (line.starts_with("#")) { ... }

  STRING INDEXING
    s[i]           - character at index i (type char); i is 0-based
    s[i] = 'x';    - replace character at i (also accepts int code point)
    Bounds are not checked (same as C++ std::string).
    Note: []string indexing still returns string (parts[i]), not char.

  Note: index directly into a split result via a variable
  (let parts = s.split(","); parts[0]), not s.split(",")[0].
